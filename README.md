

# Aplicación de Proyecto DAW
## 1. Descripción
Esta aplicación web está desarrollada en PHP y Utilizada para vizualizar trabajo echo de la asignatura de Despligue de aplicaiones web

## 2. Requisitos
- PHP 8.3 o superior.
- Un servidor web, como Apache, o el servidor de desarrollo integrado de PHP.
## 3. Instalación
Clonar el repositorio:
`git clone https://github.com/Juan-D07/JDPDAWProyectoDAW`

Acceder a la carpeta del proyecto:
`cd JDPDAWProyectoDAW`

Iniciar el servidor de desarrollo de PHP:
`php -S localhost:8000`

## 4. Uso
Una vez iniciado el servidor:

Abrir un navegador web.
`Acceder a http://localhost:8000.`
Visualiza las tareas
## 5. Estructura del proyecto

```bash
JDPDAWProyectoDAW/
├── indexProyectoDAW.php
├── .htaccess
├── docs
├── error
└── webroot
```
